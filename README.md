# ewagifts-rest-api #

## Описание #

Это приложение является API для получения данных напрямую из базы данных WordPress. Потребность разработки API исходит из того, что REST API плагина WooCommerce работает крайне медленно на сложных запросах (одновременная фильтрация по категории, метаполям и набору атрибутов).

## Детали реализации #

Все виды данных кроме товаров запрашиваются напрямую из базы данных WordPress, товары кэшируются в памяти. При запуске приложения из MongoDB берётся дамп товаров, затем начинается выборка товаров из БД WordPress, по после завершения выборки товаров кэш в памяти и дамп в MongoDB обновляются.
